# Cluster

{/* cspell:ignore valkey */}

`Cluster` is the low-level sharded topology API. A high-level `Valkey` with
`spec.arch: cluster` creates and owns this resource. Inspect it for diagnostics;
apply product-level changes to `Valkey`.
