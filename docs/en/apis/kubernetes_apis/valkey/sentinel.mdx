# Sentinel

{/* cspell:ignore valkey */}

`Sentinel` is the low-level API for Valkey Sentinel workloads. A high-level
Failover instance normally creates and owns this resource. Inspect it for
diagnostics; configure Sentinel through `Valkey.spec.sentinel`.
