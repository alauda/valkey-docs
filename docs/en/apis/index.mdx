# APIs

The API reference is generated from the CRDs copied from the inspected
`valkey-operator` 2.0.0 source baseline. Use the high-level `Valkey` and `User`
resources for product operations. Lower-level topology APIs are included for
diagnostics and schema visibility, not as the normal authoring surface.
