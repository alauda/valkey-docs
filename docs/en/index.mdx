# Alauda Build of Valkey

Alauda Build of Valkey 2.0.0 manages Valkey 7.2, 8.1, and 9.1 on Kubernetes.
The product is operated entirely through CLI and Kubernetes APIs; it does not
provide a Web Console.

## Start here

1. Read the [Introduction](./intro.mdx) and [Architecture](./architecture.mdx).
2. [Install and verify](./installation.mdx) the CRDs and Valkey Operator.
3. [Create an instance](./functions/10-create-instance.mdx).
4. Select the correct [client connection](./how_to/access/index.mdx) procedure.
5. Review [Current limitations](./limitations.mdx) before production use.
